Giving Content Meaning with HTML

Semantic HTML identifies the purpose of each part of a page. A navigation element contains navigation links, the main element holds the primary content, and an article contains a piece that can make sense on its own.

Clear headings help readers follow the page and help people using assistive technologies find the information they need. Choosing meaningful elements also makes the source easier to understand.

Making Forms Easier to Complete

Every form control needs a clear label. Connecting a label to an input helps people understand what to enter, while a fieldset and legend can explain a related group of choices.

Input types such as email and telephone describe the expected information. Required fields and length limits provide native browser validation. Clear instructions should also explain what happens when the form is submitted.

Connecting a Multi-Page Website

Consistent navigation helps visitors move between pages without learning a different menu each time. Keeping the same link labels and order makes a small website easier to explore.

Relative links connect files within the same project. For example, a link to index.html opens the homepage. Each destination should have a descriptive title and a clear main heading so visitors can understand where they have arrived.
